### 复核结论摘要

**已确认并修复**（按严重度）：

| 严重度 | 问题 | 修复 |
|---|---|---|
| 高 | `/api/sms/get` 接受客户端 `maxPriceUsd`，直通定价覆盖分支，且成交后把该数字写进**全局** PriceCache（上游价格接口不可用，缓存即唯一生效价格源）→ 任何人可永久改写某服务组合售价 | 路由不再接受价格入参；`observe` 跳过 override 来源 |
| 中 | 充值绕过池容量闸门（只有新购有） | 共用 `assertPoolCapacity` |
| 中 | 「取号后可取消等待秒数」设置不生效（闸门只读环境变量） | 改读设置（DB > env > 默认） |
| 中 | 500 回显内部异常（含数据库表名/列名） | 统一固定文案，详情只进日志 |
| 中 | 畸形 Cookie 触发 `URIError` → 受保护接口 500 | 解析加兜底，按未登录处理 |
| 中 | 可用号缓存无上界（键为客户端字符串）→ 可刷 OOM + 耗尽上游配额 | 条数上限 + 过期清理 + `country` 白名单 |

| 中 | 上游报 `NO_ACTIVATION` 时核账抛错跳过 → 该笔钱永久卡住 | 视同已取消并退款 |
| 低 | 卡密明文惰性抹除（无人查单则长期留库） | 新增定时物理清理 |
